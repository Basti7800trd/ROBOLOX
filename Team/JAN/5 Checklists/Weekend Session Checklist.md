# Weekend Session Checklist

Part of [[Roblox Home]]. For Claude (and the user) at the start and end of every weekend session.

## Start
- [ ] New Claude session in `D:\HAVIL\-Roblox\`; paste the [[Session Handover]] box.
- [ ] Studio open with the right place; `list_roblox_studios` shows it. Studio MCP down? Tell the user at once.
- [ ] ONE weekend goal picked (popup).
- [ ] The friends know what they do today ([[Team Workflow]], task list).

## During
- [ ] One to-do at a time for the user; popups for decisions.
- [ ] A changelog entry after every finished request.

## End
- [ ] Team playtest (plus a phone test when UI changed).
- [ ] [[Playtest Questions]] asked in popups; answers -> changelog, notices -> new tasks.
- [ ] Notes: [[Roblox Changelog]], [[Roblox Playbook]] lessons, checklists.
- [ ] Studio: work saved, test switches off.
- [ ] Refresh the [[Session Handover]] box (state + next changelog number).
